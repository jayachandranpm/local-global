Privacy by Architecture — Not by Promise

This isn't a cloud service that promises not to read your data. The AI literally cannot phone home — it binds to localhost only. No telemetry, no analytics, no tracking code. All your conversations and settings are stored as plain files in a local folder on your Mac — easily backed up, totally transparent. Delete the app, and everything is gone.

Get Started

Two ways to install

Choose your path — whether you want a one-click install or prefer to build from source.

Recommended

Easy Install

Best for most people. Download the app, install Ollama, and start chatting.

  1. Download the .app from the releases page
  2. Install Ollama (the free AI engine)
  3. Open Ollama and pull a model:
    ollama pull llama3.2 ollama pull gemma3:4b
  4. Double-click Local Global.app — done!
Download App
Developers

Build from Source

Full control. Clone, customize, and compile. Requires Homebrew and CMake.

  1. Install prerequisites:
    brew install cmake drogon curl jsoncpp
  2. Install Ollama + pull a model
  3. Clone and build:
    git clone https://github.com/YOUR_USERNAME/local-global.git cd local-global/myapp mkdir -p build && cd build cmake .. && cmake --build .
  4. Run the app:
    ./Local\ Global.app/Contents/MacOS/Local\ Global

FAQ

Common Questions

Is this really free? What's the catch?
Yes, 100% free and open source (MIT license). There's no catch — no freemium upsell, no ads, no data harvesting. The app runs AI models on your own hardware, so there are no server costs to pass on to you.
Do I need to be technical to use this?
Not at all! The "Easy Install" path just requires downloading two things: the app and Ollama. If you can install a Mac app, you can use this.
How good is it compared to ChatGPT?
It depends on the model you choose. Smaller models (3B–4B parameters) are great for everyday tasks. Larger models (7B–13B) approach the quality of earlier GPT versions. The trade-off is privacy and cost ($0) vs. the absolute cutting edge of cloud AI.
Will it slow down my Mac?
The AI model uses your Mac's resources only while generating a response. When idle, the app uses minimal CPU and RAM. On Apple Silicon Macs (M1+), inference is quite efficient thanks to the Neural Engine.
Can I use it without internet?
Yes! After the initial setup (downloading the app, Ollama, and a model), everything works 100% offline. The only feature that needs internet is Web Search, which is optional and off by default.
What AI models can I use?
Any model supported by Ollama's library — including Llama 3, Gemma, Mistral, Phi, CodeLlama, and many more. We recommend starting with llama3.2 for a good balance of quality and speed.
What file types can I upload?
PDF, DOCX, DOC, PPTX, XLSX, XLS, RTF, ODT, EPUB, HTML, XML, and all plain text formats (TXT, CSV, Markdown, source code files, etc.). Just drag and drop.
Does it work on Windows or Linux?
Currently macOS only. The underlying architecture (C++ with webview) is cross-platform, so Linux and Windows support could come in the future. Contributions welcome!
Is my data safe? Where are conversations stored?
All conversations, settings, and memories are stored as plain JSON files in a local folder on your Mac (app_storage/ inside the app bundle's Resources directory). Nothing is sent to the cloud — the backend binds to 127.0.0.1 (localhost only). You can open, back up, or delete these files at any time. Removing the app removes all data.
Can I contribute or report bugs?
Absolutely! The project is open source on GitHub. File issues, submit pull requests, or suggest features. All contributions are welcome.
